# 📧 Spam Detection using Logistic Regression

## 📌 Project Overview
This project builds a Machine Learning classifier to predict whether an email is spam or not spam. It uses a **Logistic Regression** model trained on features such as word frequency and email length.

## 🛠️ Technologies Used
* **Python**
* **Pandas & NumPy** (Data Processing)
* **Scikit-Learn** (Model Training & Evaluation)
* **Seaborn & Matplotlib** (Data Visualization)

## 📊 Dataset
This project uses the UCI Spambase dataset. The dataset contains quantitative features extracted from emails, including word frequencies, character counts, and continuous length attributes, with a binary target variable (1 = Spam, 0 = Not Spam).

## 🚀 Evaluation Metrics
The model's performance is thoroughly evaluated using:
* Accuracy
* Precision, Recall, and F1-Score
* Confusion Matrix (Visualized using a Seaborn heatmap)
